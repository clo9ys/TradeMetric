# TradeMetric — фронтенд

React, TypeScript, Vite. Первый этап: боковая панель и верхняя навигация по макету.

## Запуск

Из корня репозитория TradeMetric сначала перейдите в папку фронтенда:

```sh
cd frontend
npm install
npm run dev
```

Откройте адрес Local, который появится в терминале. Оставьте терминал открытым, пока работаете со страницей.

## Проверка сборки

```sh
npm run build
```

Список недавних сессий и содержимое разделов пустые; тестовые данные не добавляются. Вкладки переключают активный раздел в адресе страницы. Выбор валюты хранится только на время открытия страницы. Таблица, расчёты, авторизация и подключение API ещё не реализованы.
