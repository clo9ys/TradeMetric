# TradeMetric — фронтенд

React, TypeScript, Vite. Шаблоны страниц по макетам TradeMetric: вход, новая сессия и история.

## Запуск

Из корня репозитория TradeMetric сначала перейдите в папку фронтенда:

```sh
cd frontend
npm install
npm run dev
```

## Проверка сборки

```sh
npm run build
```

## Страницы

- `/#new` — новая сессия: пять пустых строк, ввод ISIN и объёма, добавление и удаление строк, пустые карточки результатов.
- `/#history` — шаблон просмотра сохранённой сессии без тестовых данных. Пока сессия не загружена, поля доступны только для чтения, кнопки отключены.
- `/#login` — форма входа. Можно открыть через блок «Пользователь» в боковой панели или напрямую по адресу.

Список недавних сессий пустой. Авторизация, поиск облигаций, расчёты и загрузка истории ещё не подключены к серверу. Кнопки входа и расчёта показывают соответствующее сообщение, без имитации успешного ответа. Пароль никуда не отправляется и не сохраняется.

На странице новой сессии проверяется заполнение ISIN (12 символов) и положительный целый объём; проверка существования облигации будет выполняться через API. Черновик сохраняется при переключении вкладок, но сбрасывается после перезагрузки. Валюта меняется только в интерфейсе; конвертация не выполняется.

## Структура

```text
src/
  app/                    приложение и переключение страниц
  pages/
    login/                форма входа и её стили
    new-session/          ввод новой сессии
    history/              просмотр истории
  layouts/                общий каркас с боковой и верхней панелями
  components/
    sidebar/              боковая панель
    workspace-header/     вкладки и выбор валюты
    session-panel/        общая панель с таблицей и кнопками
    trade-table/          таблица сделок
    results-cards/        карточки результатов
    icons/                общие иконки
  styles/
    tokens.css            палитра и общие переменные
    global.css            базовые стили и кнопки
  types/                  типы страниц, валют и строк таблицы
```

Локальные стили лежат рядом с соответствующими компонентами. Палитра основана на предоставленном SVG и скриншотах; для уточнения цветов меняйте переменные в `src/styles/tokens.css`. На настольном экране размеры пропорционально масштабируются от 1080 до 1440 px. На узких экранах таблица прокручивается внутри своей панели, карточки и форма перестраиваются в колонку.
