# TradeMetric — фронтенд

React, TypeScript, Vite. Страницы по макетам TradeMetric: вход, новая сессия и история. На странице новой сессии подключён локальный демонстрационный расчёт на синтетических данных.

## Запуск

Из корня репозитория TradeMetric сначала перейдите в папку фронтенда:

```sh
cd frontend
npm install
npm run dev
```

## Проверка сборки

```sh
npm run build
```

## Страницы

- `/#new` — новая сессия: ввод ISIN и объёма, загрузка трёх демо-сделок, расчёт и вывод результата.
- `/#history` — последние 20 сохранённых демо-расчётов из PostgreSQL. Можно выбрать расчёт и посмотреть его сделки, стоимость и DV01.
- `/#login` — форма входа. Можно открыть через блок «Пользователь» в боковой панели или напрямую по адресу.

Авторизация ещё не подключена к серверу. Кнопка входа показывает соответствующее сообщение; пароль никуда не отправляется и не сохраняется. Расчёт и история на странице новой сессии обращаются к локальному API через Vite proxy. Инструкция по запуску БД, API и заполнению кеша есть в корневом README.

На странице новой сессии проверяется заполнение ISIN (12 символов) и целый ненулевой объём; отрицательный объём означает короткую позицию. Ошибки показываются у соответствующих полей после выхода из строки или нажатия «Рассчитать». API принимает только три тестовых ISIN. Черновик сохраняется при переключении вкладок, но сбрасывается после перезагрузки. Демонстрационный расчёт доступен только в RUB; конвертация валют не выполняется.

## Структура

```text
src/
  app/                    приложение и переключение страниц
  pages/
    login/                форма входа и её стили
    new-session/          ввод новой сессии
    history/              просмотр истории
  layouts/                общий каркас с боковой и верхней панелями
  components/
    sidebar/              боковая панель
    workspace-header/     вкладки и выбор валюты
    session-panel/        общая панель с таблицей и кнопками
    trade-table/          таблица сделок
    results-cards/        карточки результатов
    icons/                общие иконки
  styles/
    tokens.css            палитра и общие переменные
    global.css            базовые стили и кнопки
  types/                  типы страниц, валют и строк таблицы
```

Локальные стили лежат рядом с соответствующими компонентами. Палитра основана на предоставленном SVG и скриншотах; для уточнения цветов меняйте переменные в `src/styles/tokens.css`. На настольном экране размеры пропорционально масштабируются от 1080 до 1440 px. На узких экранах таблица прокручивается внутри своей панели, карточки и форма перестраиваются в колонку.
